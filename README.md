# subin-portfolio

조수빈 포트폴리오 사이트 (정적 HTML, GitHub Pages용)

## 구조
- `index.html`: 번호 목록 + 문장 뽑기
- `projects/01.html`: 프로젝트 페이지 템플릿 (복사해서 02, 03… 만들기)
- `cv.html`: 이력서
- `magpie-and-tiger.html`: 지원처 전용 숨은 페이지 (noindex, 메인에서 링크하지 않음)
- `assets/lines.js`: 문장 뽑기 목록
- `assets/style.css`: 디자인 (서체·색은 맨 위 변수만 바꾸면 됨)

## 미리 보기
`index.html`을 브라우저로 열면 됩니다.

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소 만들기 (이름 예: `subin-portfolio`, Public)
2. 이 폴더를 그 저장소에 push
3. 저장소 Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 몇 분 뒤 `https://<아이디>.github.io/subin-portfolio/` 에서 열림

공개 저장소이므로 전화번호·주소는 넣지 말고, 외부 클라이언트 작업은 공개된 결과물만 올리세요.
